# mrkey4real.github.io

齐梓轩的个人主页。GitHub Pages 静态网站，纯 HTML 和 CSS。周记由 `build.py` 从 Markdown 生成。

## 发一篇周记

1. 在 `_posts/` 里新建 `YYYY-MM-DD-slug.md`，开头写：

   ```
   ---
   title: 标题
   date: YYYY-MM-DD
   ---
   ```

   下面写正文，英文，几句话就够。
2. 运行 `python3 build.py`。它会生成 `notes/` 下的网页，并更新首页的周记列表。
3. 提交并推送。

## 本地预览

在这个文件夹里运行 `python3 -m http.server 8000`，再用浏览器打开 http://localhost:8000 。

## 内容规矩

- 论文只列已发表的。在做的项目只写想达到的效果，不写具体的研究问题、核心方法和结果数字。
- 项目封面。已发表的用论文里的图，在做的用概念图，现场项目用现场照片。测试房子的照片放在「The test houses」那一节，不拿来当别的项目的封面。
- 项目卡片的「What I did」写用到的技术。缩写第一次出现时写全称。
- 周记写这阵子主要在干什么，不写流水账，形式不用每篇一样。可以发看法和牢骚，但只说事和工具，不点名人、导师、合作方和学校部门。
- 不放参与者的照片或视频，不放合作方的内部数据。别人的图（例如项目申请书里的图）要先征得同意再放。
- 不放电话、住址、IP 地址、账号和密码。照片放进来之前，先缩到 1600 像素以内，并去掉 GPS 等元数据。
- 主页上不放简历。
